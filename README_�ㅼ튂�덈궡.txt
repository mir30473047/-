# 이엘의 브리핑 ♡ — PWA 파일

이 폴더는 Android Chrome에서 주소창 없이 앱처럼 실행하기 위한 PWA 구성입니다.

## 중요
- `index.html` 파일만 직접 열면 앱 모드가 되지 않습니다. HTTPS 주소로 호스팅해야 합니다.
- 무료 호스팅 예: GitHub Pages. 아래 파일을 저장소의 루트에 업로드하고 Pages를 켜면 HTTPS 주소를 받을 수 있습니다.
- Chrome에서 그 HTTPS 주소를 열고 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`를 선택합니다. 설치 후 홈 화면 아이콘으로 실행하면 주소창이 없는 독립형 화면으로 열립니다.
- 기존 `file://`/`content://`로 열었던 버전의 localStorage 데이터는 새 HTTPS 사이트로 자동 이전되지 않습니다. 중요한 일정이 있다면 설치 전에 기록을 옮겨 두세요.
- PWA의 오프라인 캐시는 앱 파일을 저장하지만, 알림은 여전히 브라우저/OS 정책에 영향을 받습니다. 브라우저가 완전히 종료된 상태의 정확한 시간 알림을 보장하지 않습니다.

파일: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`
